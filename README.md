Shift-Left security pipeline execution laboratory covering SAST (SonarQube/Semgrep), secret scanning (GitLeaks), container scanning (Trivy), and OWASP dependency checks.

---

## ⚡ Quick Start

```bash
git clone https://github.com/shubhu-io/17-devops-devsecops.git
cd 17-devops-devsecops
chmod +x setup.sh
./setup.sh
```
